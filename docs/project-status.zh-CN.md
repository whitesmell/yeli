## 产品与发布

产品包含默认单文件配置与单独构建的高级配置。公开行为与信任边界见
[架构](architecture.md)和[文件格式](format.md)。内部产品契约、计划和设计资料
保留在本地，不进入公开集。

剩余工作包括：

- 在保持离线编辑、源码保真、渲染安全与 Agent 互操作的前提下完善 Zopfli + Base86。
  所有者于 2026-10-23 暂缓此前 **100,000 字节**目标；默认校验报告暂缓状态，
  并实际解压检查 carrier，保留 `--enforce-size-target` 显式检查历史目标。
  完整包体、启动与兼容性证据见[压缩实测](compression.md)。
- 重新验证 Yeli 改名后的精确产物；此前 AIMD 测量仅属于日期化证据。
- 固定正式签名公钥并建立正式发布渠道。
- 完成真机 / 辅助技术、具名传输 / 静态宿主、5 人首次使用和 3 个真实 Agent
  的授权评估。
- 在需求研究和范围复审通过前，保持实验性定位，不宣称 V1 / 稳定版。

完整门槛见[发布说明](releasing.md)。

## 明确的边界

V1 不包含内置 AI 编辑、账号、云端权威存储、同步、协作或可执行文档插件。
官方高级版是可信发行代码的独立组合。旧 `.aimd.html` 不受支持且保持原样；
内容转移只能通过显式 Markdown 导出 / 导入完成。
