# 公开仓库范围

整理日期：2026-10-25。[English](public-scope.md) · 简体中文。

采用必要公开原则：只包含构建和使用所需源码、基础文档、合成测试及自有运行素材。
项目使用 [MIT 许可证](../LICENSE)，第三方组件遵循各自条款。
所有者已确认按此范围以干净快照发布到
[whitesmell/yeli](https://github.com/whitesmell/yeli)。源码公开不代表官网上线或
可执行编辑器已发行。

## 纳入公开源码

| 目录 / 文件                                    | 用途                                                        |
| ---------------------------------------------- | ----------------------------------------------------------- |
| `.github/`                                     | CI、官网工作流、Issue 表单和 PR 模板                        |
| `src/`                                         | 文档模型、编辑器、运行时、安全与中英文 UI                   |
| `src/brand/`                                   | 运行时与官网共享的自有标志几何数据及渲染器                  |
| `site/`                                        | 官网、双语用户教程、自有网站素材、构建脚本与测试            |
| `scripts/`                                     | 文件 helper、CLI 打包、构建、校验及公开范围检查             |
| `packages/cli/`                                | 独立 CLI 的源码、启动器与包配置                             |
| `skills/yeli/SKILL.md`                         | 面向文档使用的通用 Skill                                    |
| `tests/`                                       | 单元、集成、安全、浏览器与合成夹具                          |
| `docs/` 必要文件                               | 开发、格式、架构、浏览器、Agent、发布、范围和第三方说明     |
| `README*`、`CONTRIBUTING*`、`SECURITY*`        | 中英文介绍、贡献指南与安全策略                              |
| `LICENSE`                                      | MIT 许可证全文                                              |
| `AGENTS.md`、`CLAUDE.md`、`PROJECT_CONTEXT.md` | 精简开发规则和公开产品边界，不含内部决策日志                |
| 根目录配置                                     | 依赖锁定、运行环境、构建、类型、lint、格式、测试与 Git 规则 |

`docs/` 采用必要文件白名单，新增文档须先审查用途。`docs/` 面向贡献者，
`site/docs/` 面向产品使用者。公开开发入口见
[文档索引](README.zh-CN.md)。构建所需品牌素材保留在 `src/brand/` 与
经核查的 `site/assets/`；内部设计证据不随其公开。

## 默认不公开

| 目录 / 文件                                      | 处理方式                                         |
| ------------------------------------------------ | ------------------------------------------------ |
| `intent/`、`spec/`                               | 内部产品意图、规格和规划原件；本地私有归档       |
| `docs/plans/`                                    | 内部实施、文档与发布计划；本地私有归档           |
| `docs/design/`                                   | 全部设计契约、校样和来源证据；取消此前公开白名单 |
| `reference/`                                     | 只读第三方研究材料，不纳入仓库或快照             |
| `.local-archive/`                                | 私有会话、QA、工作 issue、研究与原始证据         |
| `output/`                                        | 本地交付、审阅快照和验证记录；不整目录公开       |
| `reports/`、`ideation/` 和内部研究 / 评审目录    | 必要材料私有保留                                 |
| `node_modules/`、coverage、浏览器报告、缓存      | 可重建输出，不提交                               |
| `session-log.md`、`design-qa.md`、`issues*.html` | 私有工作记录                                     |
| 本地环境、凭据、私钥、真实用户文档与恢复数据     | 不纳入源码、CI 或公开报告                        |

不公开不等于删除。原始契约与必要私有证据完整保留；旧 issue 不转换或覆盖。
公开文档不依赖上述内部目录，不使用第三方产品类比描述自身编辑体验。
将来需要公开其中材料时，须先逐项确认必要性、来源和隐私，不能直接放开目录。

## 语言与分发

简体中文统一为 `zh-CN`，英文为 `en`；`zh-Hans` 是兼容输入别名。
界面语言偏好不改写文档语言。旧 `.aimd.html` 的拒绝逻辑与合成测试继续公开。

源码不包含 `dist/`。发布验证通过后，中英文起始文件在 Release 单独上传，
各自附 manifest 和校验和。空白与高级版按[发布说明](releasing.md)单独验证。

```text
dist/
  html/         中英文起始文件
  empty/        空白文件
  advanced/     可选高级版
  cli/          编译后的 CLI
  packages/     CLI 安装 tarball
  web/          开发网页构建
  site/         官网、教程与可编辑手册
  releases/     网站上传归档与校验和
```

官网示例使用当次起始产物，教程由 `site/docs/` 生成；源码中不维护编译副本。
CLI 和通用 Skill 源码公开；npm 保持 `private: true`，发包另行确认。

## 提交和历史边界

运行 `npm run check:public` 检查已跟踪文件和未被忽略的新文件。即使强制添加
内部契约、设计文件或第三方参考目录，检查也会失败。删除的跟踪路径不进入
工作区候选集；未来整理提交应记录相应删除。

`.gitignore` 不会移除已跟踪文件，也不会清除旧提交。现有开发历史包含私有记录，
不能直接推到公开仓库。公开必须使用核查后的干净源码快照，或另行审核历史清理。
路径检查不代替内容、素材来源与历史审查；旧审阅快照不自动适用于当前范围。
