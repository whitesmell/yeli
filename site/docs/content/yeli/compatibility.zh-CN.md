# 兼容性、安全与排错

## 浏览器能力不是统一承诺

当前产物有 Chromium 与 Firefox 自动化证据；不能据此声称 Safari 或所有手机均已认证。直接写回通常依赖支持文件访问 API 的浏览器、运行环境与授权；否则使用下载副本。JavaScript 被禁用时只有有界静态预览，不能编辑，且 Agent 修改后该预览可能过期。

默认构建提供页面编辑和区块原文。官方增强构建另外带整篇源码与源码 + 预览；它需要独立构建文件，不是从文档内安装任意插件，也不会增加未启用的图表/数学能力。

## 按症状处理

| 症状                 | 下一步                                               |
| -------------------- | ---------------------------------------------------- |
| HTML 附件不能打开    | 下载到本地浏览器，或请发送方提供只读输出             |
| 页面只有摘要         | 确认脚本没有被附件预览器禁用；从可信原始文件打开     |
| 保存下载了另一个文件 | 这是降级路径，确认下载完成并重开最新副本             |
| 历史不可用           | 看“关于”的存储状态，及时保存文件；不要先清除站点数据 |
| 图片不显示           | 远程/相对路径未嵌入，选择本地图片重新加入            |
| 属性不能编辑         | 检查复杂值、歧义或重复 YAML 字段，保留原文           |
| 演示不可用           | 检查至少两个同级顶层标题，见阅读与演示               |
| 打开旧格式失败       | 保留 `.aimd.html`，通过旧工具导出 Markdown           |
| 文件过大             | 压缩图片或拆分内容，再核对完整文件字节               |

## 来源与权限

可编辑 HTML 包含代码，只打开可信发送者或托管源的文件。文档内“校验通过”不能让不可信代码变可信。Yeli 不自动执行正文 HTML、脚本或远程图片；外部链接由你决定是否打开。

文件访问、覆盖、恢复删除与壳迁移均应由人决定。当前没有浏览器内自动更新运行壳的流程。分享阅读内容优先[静态导出](export.html)。
