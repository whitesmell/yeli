# Your first edit and save

## Obtain a trusted file

Get a `.yeli.html` from a source you trust, download it and open it in a browser. No account or server is required. Attachment previews may disable interaction; download the file before editing instead of working inside a thumbnail viewer.

## Complete the first round trip

1. Choose Edit in the preview. Click a paragraph and write “My first Yeli document”.
2. Change the document title at the top. For a section, type `/` in an empty block and choose a level-two heading.
3. Press `⌘/Ctrl + S`, or open More and choose Save or Download updated copy directly. File is a section label, not a submenu. Read the result: Yeli may write back or download a new copy.
4. If it wrote back, locate the original file; if it downloaded, find the latest `.yeli.html` in Downloads. Reopen the actual saved file and confirm the title and your text survived.

Success means **your edits appear after reopening the saved file**. Browser recovery records and visible page content do not replace a file on disk.

## Start another document

Keep an untouched trusted starter and make a copy for each document. Alternatively, choose More → Open file in an existing Yeli document, import a new `.md` file and save it as `.yeli.html`. There is no required account or cloud New document workflow.

## Check before sharing

Share a trusted editable copy when the recipient should continue writing. Use a read-only export for reading. Email and chat services may block HTML attachments; check the delivery channel first. Continue with [saving and conflicts](save.html) and [import and export](export.html).
