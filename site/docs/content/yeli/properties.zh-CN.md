# 文档属性与 frontmatter

## 从常用信息开始

标题附近编辑常用作者与标签；在编辑模式打开右侧“文档”面板补充描述。展开组织/作者信息可维护相应字段。所有信息仍写入 Markdown 顶部的 YAML frontmatter，而不是另建隐藏属性库。

## 添加自定义属性

在自定义属性区域填写唯一字段名并选择类型：文本、数字、开关、日期、文本列表。可筛选大量属性、编辑已有值或删除属性；删除可撤销。

```yaml
---
title: 项目手册
tags: [指南, 内部]
budget: 1200
approved: false
review_date: "2026-10-24"
owners: [Lin, Sam]
---
```

`review_date` 是日期形态的字符串，不会自动计时或触发工作流。数字必须有限；过大而不能安全精确表达的整数保留为只读。文本列表按条目填写，不把逗号误当成任意对象序列化入口。

## 提交与保护

普通单行输入可用 Enter 或移出焦点提交，Escape 取消草稿；多行和列表字段用 `⌘/Ctrl + Enter` 提交。并发修改同一值可能被拒绝，重新检查现值后再编辑。

嵌套对象、null 和复杂值只读保留；重复字段或歧义 YAML 会禁用表单，避免误改。用区块原文或外部工具修正时保留备份。详情见[frontmatter 教程](../markdown/frontmatter.html)。
