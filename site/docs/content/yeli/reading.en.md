# Read, focus and present

## Read comfortably

Switch to Preview to hide writing tools and use the outline to navigate. Open More and choose Font size, Page width or Focus directly in its View section. Font size has three settings; width offers default, wide and full. These settings change layout without rewriting Markdown.

Focus hides supporting panels so you can work with fewer distractions. Exit it to resume the previous workspace. There is no document-configured theme plugin or online font service to install.

## Prepare headings for presentation

Presentation divides content at level-one headings when at least two exist. With no level-one headings and at least two level-two headings, it uses level two. One level-one heading followed by multiple level-two headings does not meet the current rule. A `#` inside a code fence is not a slide heading.

```markdown
# Background

Describe the problem.

# Decision

Describe the next step.
```

Open Present or press `⌘/Ctrl + Shift + Enter`. Left/Right move between sections. Escape exits; in fullscreen it first leaves fullscreen. Fullscreen depends on browser support and user interaction; presentation can still run in a normal window.

## Check delivery

Presentation is a reading surface, not a conversion to a separate slide-data format. For PDF, use [print/export](export.html) and inspect pagination, tables and images. A screenshot of presentation is not a substitute for a saved document.
