# 图片与离线资源

## 把图片带进文件

在 `.yeli.html` 的编辑模式打开顶部“插入”菜单，选择“图片”。也可以从空白块菜单、块菜单的“在下方插入”，或输入 `/图片` 插入。新图片占位块会获得焦点并打开右侧属性面板，点击“选择图片”，选取本地 PNG、JPEG、GIF 或 WebP。图片嵌入 `.yeli.html`，与对应 Markdown 引用共同保存。SVG 不是当前图片导入格式；超出大小、数量或总资源预算会被拒绝，先压缩图片再重试。

## 修改与预览

在线编辑器也支持“选择图片”，图片仅留在本机。添加图片后，保存项变为“下载含图片的 Yeli”，下载包含正文和图片数据的可编辑 `.yeli.html`；打开下载文件即可继续离线编辑。连接的原 `.md` 文件会保留；含内嵌图片时会阻止 Markdown 保存和导出，避免丢失图片数据。撤销或删除最后一张内嵌图片后恢复 Markdown 保存。

选择图片可在右侧查看说明、标题和来源，并执行替换、复制或删除。替换选择新的本地图片；删除按实际引用处理附件，不应手工修改内部资源 ID。打开图片预览查看细节，Escape 关闭，再保存新副本核对。

替代文字应说明图片传达的信息，例如“第一季度三种方案成本对比”，而非“图片 1”。它帮助无法看见图片的读者理解正文。

## 外部地址并不等于嵌入

Markdown 中的远程图片地址和相对路径不会因为打开文档就自动下载。当前会显示未加载提示；把需要离线交付的图片通过本地文件选择嵌入。界面没有提供加载动作时，不要期待点击正文就能联网补全资源。

导出时查看遗漏图片提示。纯 `.md` 导出不会同时打包内嵌二进制图片；需要单文件图片交付时保留 Yeli 或核对只读 HTML。详见[导入导出](export.html)。
