# 功能总览与使用入口

Yeli 把 Markdown 正文、图片和阅读编辑环境装进一份 `.yeli.html`。下载可信文件后，用浏览器打开即可阅读；选择“编辑”开始写作。先用这页找到需要的能力，再进入对应教程。

## 先选你的目标

| 我现在要做什么                      | 从哪里开始                              |
| ----------------------------------- | --------------------------------------- |
| 第一次打开、写几句话并保存          | [快速开始](quickstart.html)             |
| 看懂工具栏、目录和右侧面板          | [认识工作区](workspace.html)            |
| 查一个按键组合                      | [快捷键速查](shortcuts.html)            |
| 查所有命令和使用条件                | [完整命令参考](commands.html)           |
| 学会议、长文或分享流程              | [工作流与最佳实践](best-practices.html) |
| 了解 Markdown、Agent 与 Yeli 的关系 | [为什么是 Yeli](mission.html)           |

下表的“更多 → 保存”等写法，表示打开顶部末尾的“更多”后直接选择该项。文件、导出、视图、设置与帮助是菜单中的**分区标签**，不需要先进入同名子菜单。具体保存项会随浏览器能力变化。

## 打开与写作

| 功能                                 | 入口和操作                                      | 什么时候用 / 详解                                                       |
| ------------------------------------ | ----------------------------------------------- | ----------------------------------------------------------------------- |
| 离线打开                             | 下载 `.yeli.html`，用浏览器打开                 | 无账号、无需服务；附件预览不能编辑时先下载。[快速开始](quickstart.html) |
| 开始新文档                           | 复制可信起始文件；或“更多 → 打开文件”导入 `.md` | 一份文件对应一份文档，先保留当前工作。[快速开始](quickstart.html)       |
| 预览 / 编辑                          | 顶部“编辑”或“预览”                              | 阅读时隐藏写作工具，修改时直接操作正文。[工作区](workspace.html)        |
| 编辑正文与标题                       | 编辑模式点击正文或顶部文档标题                  | 先写内容，再调整格式。[正文编辑](writing.html)                          |
| 文字格式                             | 选中文字，使用浮动工具或快捷键                  | 粗体、斜体、删除线、行内代码、链接、清除格式。[选区编辑](writing.html)  |
| 标题、列表、待办、引用、代码、分隔线 | 顶部“插入”；空白区块 `+` 或输入 `/`             | 用结构表达层级；标题支持 H1–H6。[区块与斜杠](blocks.html)               |
| 区块转换、复制、删除                 | 目标区块的类型菜单                              | 调整已有内容；复杂区块只提供可安全执行的操作。[区块操作](blocks.html)   |
| 会议记录模板                         | 插入菜单中的模板分组                            | 建立结论和下一步的骨架；日期和参与者需要填写。[模板](blocks.html)       |
| 局部 Markdown 原文                   | 对应区块的“编辑区块原文”                        | 处理无法直接编辑的结构，提交前核对范围。[局部原文](writing.html)        |

## 组织与查找

| 功能           | 入口和操作                                | 什么时候用 / 详解                                                                 |
| -------------- | ----------------------------------------- | --------------------------------------------------------------------------------- |
| 标题目录       | 左上角 Yeli 标志；`⌘/Ctrl + Shift + O`    | 按标题跳转、折叠层级；目录内筛选只找标题。[工作区](workspace.html)                |
| 全文搜索与替换 | 顶部搜索；`⌘/Ctrl + F`                    | 搜正文；编辑模式可检查匹配后替换。[搜索替换](search.html)                         |
| Markdown 表格  | 插入 → 表格，选行列；单元格内显示结构工具 | 简单行列数据、增删行列；没有公式或合并单元格。[表格](tables.html)                 |
| 图片与离线资源 | 编辑时使用图片插入入口，选中图片编辑说明  | 嵌入需要随文件带走的图片，远程图片按提示授权。[图片](media.html)                  |
| 常用属性       | 标题附近的作者和标签；右侧“文档”面板      | 填写描述、组织与作者信息。[文档属性](properties.html)                             |
| 自定义属性     | 文档面板的自定义属性区域                  | 文本、数字、开关、日期和文本列表；复杂 YAML 只读保留。[属性类型](properties.html) |

## 保存、历史与交付

| 功能           | 入口和操作                                    | 什么时候用 / 详解                                                         |
| -------------- | --------------------------------------------- | ------------------------------------------------------------------------- |
| 保存当前修改   | `⌘/Ctrl + S`；更多中的保存项                  | 根据权限写回原文件或下载更新副本；以提示和实际文件为准。[保存](save.html) |
| 保存独立副本   | 更多 → 保存副本                               | 做阶段备份、交给他人继续编辑。[副本](save.html)                           |
| 冲突与重新关联 | 按冲突或文件关联提示处理                      | Agent 或外部工具改过文件后，先保留两边内容。[冲突](save.html)             |
| 撤销与重做     | 顶部按钮；`⌘/Ctrl + Z` / `⌘/Ctrl + Shift + Z` | 回退当前编辑会话的操作。[历史与撤销](history.html)                        |
| 版本历史与恢复 | 编辑模式“更多 → 历史”                         | 先看差异、确认后恢复，最后仍需保存。[版本历史](history.html)              |
| 浏览器草稿恢复 | 重新打开时按提示选择                          | 记录依赖当前浏览器与来源，不随文件走。[恢复范围](history.html)            |
| 导出 Markdown  | 更多 → 导出 Markdown                          | 带走可读原文；内嵌图片不会随 `.md` 自动打包。[导出](export.html)          |
| 只读 HTML      | 更多 → 导出只读 HTML，检查导出预览            | 给只需阅读的接收方；输出不含编辑器脚本。[分享](export.html)               |
| 打印 / PDF     | 更多 → 打印 / PDF                             | 在打印对话框选打印机或保存 PDF，检查分页。[打印](export.html)             |

| 功能            | 入口和操作                            | 什么时候用 / 详解                                                                |

| 字号与页面宽度  | 更多 → 字体大小 / 页面宽度            | 只调整布局，不改正文；宽表可选择宽屏。[阅读布局](reading.html)                   |
| 专注            | 更多 → 专注                           | 临时收起辅助区域，集中写作或阅读。[专注](reading.html)                           |
| 演示            | 更多 → 演示；`⌘/Ctrl + Shift + Enter` | 按符合规则的 H1 或 H2 分节演示。[演示规则](reading.html)                         |
| 中英界面        | 更多中的语言选项                      | 切换界面用语；不会翻译正文或修改文档 `lang`。[工作区](workspace.html)            |

## 使用前知道的边界

浏览器历史不等于同步或备份，多人交换副本需要自行约定哪一份是最新文件。表格不是电子表格，任务复选框不发送提醒，自定义属性不自动触发流程。

仅打开可信来源的可编辑 HTML；公共阅读选择静态输出。直接保存、草稿恢复、附件传输都有环境限制，遇到问题查[兼容性与排错](compatibility.html)，判断语法是否启用查 [Markdown 支持表](../markdown/extensions.html)。

知道要用哪些功能之后，可以用[最佳实践](best-practices.html)把它们连成一次完整工作。
