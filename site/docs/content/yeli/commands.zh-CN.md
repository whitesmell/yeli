先按目的找到分组，再看“操作入口”和“生效条件”。命令 ID 用于对照实现、复现问题和维护文档，不需要在正文或浏览器控制台输入。下列目录也不是 CLI 子命令列表，Agent 文件操作见 [Agent 教程](agent.html)。

## 为什么某项操作不可用

| 现象                 | 先检查                           | 下一步                             |
| -------------------- | -------------------------------- | ---------------------------------- |
| 找不到格式或插入     | 是否处于预览                     | 进入编辑，再选择目标               |
| 加粗、链接等无效     | 是否有可编辑文字选区             | 重新选中文字，使用浮动工具         |
| 转换或区块操作不可用 | 是否可安全转换，是否已是目标类型 | 先操作简单段落；复杂结构用局部原文 |
| 表格增删不出现       | 焦点是否在单元格内               | 单击目标单元格，核对当前行列       |
| 撤销或重做不可用     | 当前会话是否有对应操作           | 会话撤销不能代替长期版本历史       |
| 演示无法打开         | 标题是否符合分节规则             | 查[演示说明](reading.html)         |

本页列出应用命令目录；全部功能及菜单流程以[功能总览](overview.html)和各章操作教程为准。
