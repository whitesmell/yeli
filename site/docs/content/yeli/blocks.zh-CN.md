# 区块、斜杠与模板

## 插入结构

顶部插入、空白区块按钮和区块间插入提供段落、标题、无序/有序列表、待办、引用、代码块、分隔线与表格。不同入口的项目数量可能不同；空白区块与斜杠菜单支持一至六级标题。

在空白区块输入 `/` 打开斜杠菜单，输入关键词筛选，用上下箭头选择、Enter 执行、Escape 关闭。Home / End 可跳至候选首尾。选择后生成普通 Markdown，而非独立的私有区块格式。

## 调整已有区块

通过区块菜单在下方插入、复制、删除，或转换为段落、各级标题、待办、引用、列表与代码。转换取决于目标是否可安全表达；跨行复杂区块可能不允许某项转换。可转换的多区块选区可一并转换，不能转换时保留原文。

复制会复制内容，删除后可撤销。先操作一小段并检查结果，再处理较长内容；目录随标题变化更新。

## 会议记录模板

插入菜单中的会议记录模板提供日期、参与者、结论和下一步任务的骨架。模板只追加普通 Markdown，不会自动填充真实日期、安排提醒或发送通知。

练习：插入会议记录，写一个结论和一个未完成任务，预览后再进入编辑勾选任务。需要行列数据时继续学习[表格](tables.html)。
