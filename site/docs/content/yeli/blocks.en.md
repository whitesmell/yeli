# Blocks, slash commands and templates

## Insert structure

Top insertion, empty-block controls and between-block insertion provide paragraphs, headings, bullet and numbered lists, tasks, quotes, code blocks, dividers and tables. Available items differ by entry point; empty-block and slash menus include heading levels one through six.

Type `/` in an empty block to open the slash menu. Filter with keywords, use Up/Down to select, Enter to execute and Escape to close. Home / End select the first or last candidate. The action creates ordinary Markdown, not a private block format.

## Change an existing block

The block menu offers insert below, duplicate, delete, and conversion to paragraphs, heading levels, tasks, quotes, lists or code. Conversion depends on whether the target can be expressed safely; complex multiline blocks may disable some conversions. A selection of convertible blocks can be converted together. Unsupported conversions preserve the source.

Duplication copies content and deletion can be undone. Try a small passage and inspect the result before changing longer content. The outline updates when headings change.

## Meeting notes template

The meeting-notes template inserts a skeleton for date, participants, decisions and next steps. It appends ordinary Markdown. It does not fill in an actual date, schedule reminders or send notifications.

Try inserting meeting notes, writing a decision and adding an unfinished task. Preview it, then return to Edit and check the task. For rows and columns, continue with [tables](tables.html).
