# 阅读、专注与演示

## 舒适阅读

切到预览隐藏写作工具，用目录跳到章节。打开“更多”，在视图分区直接选择“字体大小”“页面宽度”或“专注”。字号可在三档间选择；页面宽度有默认、宽屏与全宽。它们改变阅读布局，不改写 Markdown 内容。

专注模式收起辅助区域，退出后继续原来的工作。当前没有需要在文档中配置的主题插件或在线字体服务。

## 让文档可以演示

演示按一级标题分节；至少有两个一级标题时可用。没有一级标题而有至少两个二级标题时，按二级标题分节。只有一个一级标题再配多个二级标题，不符合当前规则；代码围栏里的 `#` 不会生成页面。

```markdown
# 背景

说明问题。

# 决策

说明下一步。
```

使用“演示”或 `⌘/Ctrl + Shift + Enter` 打开。左右箭头切换章节；Escape 关闭演示，全屏状态下先退出全屏。全屏取决于浏览器支持与用户操作，演示仍可在普通窗口使用。

## 交付前检查

演示是一种阅读方式，不会把文档转换成另一套幻灯片数据。需要 PDF 时使用[打印/导出](export.html)，检查分页、表格与图片，而不是截取演示窗口当作唯一备份。
