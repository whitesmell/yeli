# 认识工作区

## 阅读与编辑

阅读模式显示“编辑”动作；编辑模式用于写作，显示“阅读”动作。只显示切换到另一状态的按钮。导出预览用于检查交付物，不是第三个日常模式。

阅读到一处再进入编辑时，Yeli 会尽量把你带到对应内容。不要为了改一句话从头寻找全文。

## 三个区域

- 左侧目录来自正文标题，可跳转并折叠标题层级。它不存放版本历史。
- 中间是正文；标题附近放置常用标签和作者信息。标题按文档当前内容派生，修改后检查正文及属性是否符合预期。
- 右侧检查器展示文档属性，或所选图片的说明与操作。历史和效率指南也会按需占用右栏。窄屏面板可能覆盖正文，先关闭面板再继续写作。

## 工具出现在哪里

| 你正在做什么         | 应该找哪个入口                        | 为什么有时看不到                             |
| -------------------- | ------------------------------------- | -------------------------------------------- |
| 显示或收起目录       | 左上角整组 Yeli 标志                  | 窄屏以抽屉显示；关闭抽屉再操作正文           |
| 改文档标题           | 顶部文档标题                          | 先进入编辑                                   |
| 撤销、重做、插入结构 | 顶部编辑工具                          | 只在编辑中显示；窄屏部分操作收进更多         |
| 给一句话加格式       | 选中文字后的浮动工具                  | 没有选区时不显示；这不是常驻工具栏           |
| 转换、复制、删除段落 | 目标区块旁的类型入口                  | 跟随当前区块；选区工具出现时其它区块入口收起 |
| 插入新结构           | 空白区块的 `+` 或 `/`，也可用顶部插入 | 空白区块与非空区块的入口不同                 |
| 调整表格行列         | 点击表格单元格后出现的工具            | 离开表格即隐藏                               |
| 找正文、做替换       | 顶部搜索                              | 替换只在编辑可用；目录筛选不搜正文           |
| 修改描述、自定义属性 | 编辑中的“文档”按钮                    | 右栏按当前任务切换，不是永久并列的多个面板   |

## 菜单入口

编辑模式顶部右侧常显“菜单”按钮，阅读模式使用三点入口。菜单按文件、导出、视图、设置与帮助组织操作。历史只在编辑模式出现；“关于 Yeli”显示当前完整文件大小、实际保存与恢复状态，展开后查看环境与附件信息。

这些名称是分区标签，不是中间子菜单。例如保存时打开“菜单”，直接选“保存”或“下载更新副本”；查看历史时直接选“历史”。“页面宽度”和“字体大小”再展开选具体档位。

菜单末尾可切换 English / 简体中文。界面语言不会自动翻译正文，也不会改写 YAML 中的 `lang`。本教程的语言切换同样只切换教程页面。

## 找不到操作时

先看自己是在阅读还是编辑，再选择目标；无选区时加粗命令不可用是正常情况。想查功能到[功能总览](overview.html)，只查按键到[快捷键速查](shortcuts.html)，核对全部命令与条件到[完整命令参考](commands.html)。
