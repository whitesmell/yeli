# 搜索与替换

## 找到内容

用工具栏搜索或 `⌘/Ctrl + F` 打开全文搜索，输入文字。匹配项会显示上下文并跳到正文对应位置；Enter 前往下一项，Shift + Enter 前往上一项，Escape 关闭。搜索不是远程检索，也不搜索你的整个磁盘。

## 编辑模式下替换

在编辑模式输入替换内容，可替换当前匹配或全部匹配。先核对上下文，特别是代码、链接与格式标记附近；执行后查看结果，必要时撤销。预览模式只查找，不直接改文。

搜索索引会随内容更新。若提示搜索时间或预算受限，结果可能不完整；不要把“全部替换”理解为所有文件或所有隐藏数据都已更新。当前搜索不是正则表达式控制台。

## 一个可靠练习

在正文两处写“待确认”，搜索它，把当前项替换为“已确认”，检查另一项仍在，再撤销。编辑后的结果通过[保存](save.html)写入文件，关掉搜索不等于保存。
