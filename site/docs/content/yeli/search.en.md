# Find and replace

## Locate text

Open search from the toolbar or with `⌘/Ctrl + F`, then enter text. Results show context and navigate to the corresponding document location. Enter moves forward, Shift + Enter moves backward and Escape closes search. It searches locally within the document, not across your disk or the web.

## Replace in Edit

In Edit, enter replacement text and replace the current match or all matches. Inspect context first, especially around code, links and formatting markers. Review the result and undo if necessary. Preview supports finding but does not directly change the document.

The index updates with content changes. A time or budget warning means results may be incomplete. Replace all does not mean every file or every hidden data field has been updated. The current search is not a regular-expression console.

## Try a controlled replacement

Write “Pending” in two places, search for it and replace the current result with “Confirmed”. Verify that the other occurrence remains, then undo. [Save](save.html) writes the edited result into a file; closing search does not save it.
