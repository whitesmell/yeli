# 编辑表格

## 创建与填写

在插入菜单选择表格，使用尺寸选择器确定可见行列数，其中第一行是表头；方向键可移动选择。例如选择 3 行 2 列，得到 1 行表头和 2 行正文。生成后修改各单元格。表头下的分隔行是 Markdown 结构，不能当作一条业务记录。

```markdown
| 项目 | 数量 |
| :--- | ---: |
| 笔记 |    3 |
```

左侧冒号表示左对齐，右侧冒号表示右对齐。表格中显示 `|` 需写作 `\|`；复杂格式可用区块原文仔细修改。

## 增删行列

点击表格单元格后，使用上下文工具在上方/下方插入行、左侧/右侧插入列，或删除当前行列；最后一行或最后一列不能删除。操作作用于当前表格，撤销可回退。删除前核对当前单元格和表格范围，避免误删数据。

## 能力边界

这是 Markdown 表格，不是电子表格。当前没有合并单元格、公式计算或数据库关系。长内容可能在表格内部横向滚动；减少列数比缩小整篇字号更易阅读。

练习：建立两列表格，增加一行，再撤销；导出 Markdown 确认是可读的管道表格。语法详见[表格与任务](../markdown/tables-tasks.html)。
