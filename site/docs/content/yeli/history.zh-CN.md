# 历史、恢复与撤销

## 打开版本历史

在编辑模式选择“更多 → 历史”，右侧显示本浏览器的版本列表。版本摘要说明改动类型，选择旧版本先预览内容与图片变化；可筛选记录。提交编辑后新版本会稍后出现在已打开列表中，不要求反复开关面板。

## 确认后恢复

选择不同版本，阅读摘要并勾选确认后恢复。恢复替换当前内容及该版本可恢复的图片；旧记录无图片历史时会说明如何保留当前图片。恢复可撤销，最后仍需保存文件。

如果选中版本与当前内容一致，界面说明无需恢复，并可“选择其他版本”；此时没有可执行的恢复操作，不是恢复失败。

## 重新打开时的恢复

在支持的来源与存储环境中，Yeli 可提示恢复未保存草稿。核对时间和内容，再由你决定恢复或放弃。恢复删除需要明确的人为动作，不应作为常规排错第一步。

记录只属于当前浏览器与来源中的本地文档实例，不随 `.yeli.html` 发送。复制文件、换浏览器、清除站点数据或隐私模式可能使历史不可用；相同文档 ID 也不代表共享历史。

## 不可用时

`file://`、精确本地回环 HTTP 和发行壳明确允许的 HTTPS 来源才可能使用持久恢复，还取决于 IndexedDB 是否可用。普通 HTTPS 托管并不自动获得该能力。查看“关于”的实际状态，及时下载副本。
