# 导入、导出与分享

## 在线编辑器与本地 `.yeli.html`

在线编辑器用于在本机处理 Markdown，不上传文件。网页打开 `.md` 后，保存会下载 Markdown；需要一份可离线继续编辑的完整文件时，选择“导出可编辑 .yeli.html”。下载后从本机打开该文件即可继续编辑。网页入口是否可用以当前发布页为准，这不代表已经部署到固定地址或提供云端存储。

本地 `.yeli.html` 是可编辑工作文件：可在浏览器离线打开，保存或另存副本仍留在本机。不要把浏览器“另存网页”当作 Yeli 保存，也不要把网页草稿当成已保存文件。

## 导入 Markdown

“更多 → 打开文件”可选择 `.md` 或 Yeli 文件。导入 `.md` 后保留标准正文，保存会生成新的 `.yeli.html`。相对图片路径没有自动变成附件，检查图片并重新嵌入。打开另一文件前先保存当前工作。

旧 `.aimd.html` 不会被自动打开或转换。保留原始文件，用旧工具导出 `.md` 后再导入；不要只改扩展名。

## 输出形式

| 目标              | 选择                                 | 需要检查                                    |
| ----------------- | ------------------------------------ | ------------------------------------------- |
| 网页带走 Markdown | 网页 → 下载 Markdown / 导出 Markdown | 内嵌图片没有随 `.md` 打包                   |
| 离线继续编辑      | 网页 → 导出可编辑 .yeli.html         | 下载完成后重新打开实际 `.yeli.html`         |
| 在本地继续编辑    | 保存 Yeli / 保存副本                 | 来源信任、完整文件、最新内容                |
| 只读网页          | 导出只读 HTML                        | 导出预览、遗漏资源、链接                    |
| 通过浏览器打印    | 通过浏览器打印导出 PDF…              | 打印对话框、分页与边距；不自动保存 PDF 文件 |

只读 HTML 经过安全渲染，不包含编辑器与脚本。导出预览用于检查该输出；确认后下载。可编辑 `.yeli.html` 仅在可信模板通过构建校验时开放；模板缺失或校验失败只会禁用该导出，Markdown、只读 HTML 和打印仍可使用。下载完成后重新打开实际文件，确认正文和设置可离线继续编辑。

“通过浏览器打印导出 PDF”是浏览器打印流程的说明，不是自动落盘承诺。Yeli 只打开打印对话框，由你选择打印机或系统提供的“保存为 PDF”目标；不同浏览器分页可能不同，需在预览中检查。

## 分享与校验

不要用浏览器“另存网页”替代文档保存。分享前重新打开实际输出检查；有图片遗漏提示时先处理或接受明确的缺失，再交付。可编辑 HTML 属于可信来源主动内容，公共阅读宜用静态输出。详见[安全与兼容性](compatibility.html)。
