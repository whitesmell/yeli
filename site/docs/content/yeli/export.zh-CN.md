# 导入、导出与分享

## 导入 Markdown

“更多 → 打开文件”可选择 `.md` 或 Yeli 文件。导入 `.md` 后保留标准正文，保存会生成新的 `.yeli.html`。相对图片路径没有自动变成附件，检查图片并重新嵌入。打开另一文件前先保存当前工作。

旧 `.aimd.html` 不会被自动打开或转换。保留原始文件，用旧工具导出 `.md` 后再导入；不要只改扩展名。

## 输出形式

| 目标     | 选择                 | 需要检查                     |
| -------- | -------------------- | ---------------------------- |
| 继续编辑 | 保存 Yeli / 保存副本 | 来源信任、完整文件、最新内容 |
| 带走原文 | 导出 Markdown        | 内嵌图片没有随 `.md` 打包    |
| 只读网页 | 导出只读 HTML        | 导出预览、遗漏资源、链接     |
| 打印归档 | 打印 / 保存 PDF      | 浏览器打印对话框、分页与边距 |

只读 HTML 经过安全渲染，不包含编辑器与脚本。导出预览用于检查该输出；确认后下载。打印打开浏览器对话框，由你选择打印机或 PDF；不同浏览器分页可能不同。

## 分享与校验

不要用浏览器“另存网页”替代文档保存。分享前重新打开实际输出检查；有图片遗漏提示时先处理或接受明确的缺失，再交付。可编辑 HTML 属于可信来源主动内容，公共阅读宜用静态输出。详见[安全与兼容性](compatibility.html)。
