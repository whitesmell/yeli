# 快捷键速查

这页只列快捷键和局部交互键。找菜单入口看[功能总览](overview.html)，查没有快捷键的操作看[完整命令参考](commands.html)。

## 先记住这几个

日常先记：保存 `⌘/Ctrl + S`、查找 `⌘/Ctrl + F`、撤销 `⌘/Ctrl + Z`、加粗 `⌘/Ctrl + B`。不确定时，用 `⌘/Ctrl + /` 打开应用内“快捷键与 Markdown 指南”；再按一次可关闭。

`⌘` 是 Mac 的 Command，`Shift` 是换挡键，`Ctrl` 是 Control。组合键中的各键同时按下。“—”表示该列没有登记按键。下面按平台分列，不需要把 `⌘` 和 `Ctrl` 一起按。快捷键表从当前应用目录生成；窄屏可左右滑动表格，查看另一平台和生效条件。

## 不按快捷键，也能完成

- 保存：打开“更多”，选择当前保存项。支持写回的环境可保存原文件，其它环境下载更新副本；成功与否要检查实际文件。
- 搜索：点顶部搜索按钮。查正文使用全文搜索；左侧目录的筛选只查标题。
- 目录：点左上角整组 Yeli 标志开关目录。
- 字号、页面宽度、演示：在“更多”选择“字体大小”“页面宽度”或“演示”。字号与页面宽度组合键循环切换档位；演示组合键打开或关闭演示。
- 选区格式：进入编辑，选中文字，再用浮动工具。没有选区时不靠反复按键解决。

## 局部交互键

这些键只在对应控件或视图中生效，不是全局命令。

| 当前场景        | 按键                            | 结果                                 |
| --------------- | ------------------------------- | ------------------------------------ |
| 空白区块        | `/`                             | 打开斜杠菜单；继续输入关键词筛选     |
| 斜杠菜单        | `↑` / `↓`、`Home` / `End`       | 选择上一项 / 下一项，跳到首项 / 末项 |
| 斜杠菜单        | `Enter` / `Escape`              | 执行选中项 / 关闭菜单                |
| 搜索输入        | `Enter` / `Shift + Enter`       | 定位下一项 / 上一项                  |
| 搜索面板        | `Escape`                        | 关闭搜索，返回原来的位置             |
| 表格尺寸选择器  | 方向键、`Enter` / `Space`       | 移动尺寸选择，激活当前按钮           |
| 属性单行输入    | `Enter` 或移出焦点；`Escape`    | 提交；取消当前草稿                   |
| 属性多行 / 列表 | `⌘/Ctrl + Enter`；`Escape`      | 提交；取消当前草稿                   |
| 演示            | `←` / `→`；`Escape`             | 上一节 / 下一节；退出全屏或关闭演示  |
| 可关闭的弹窗    | `Tab` / `Shift + Tab`；`Escape` | 移动焦点；关闭                       |

## 按了没有反应时

1. 先看模式和目标：文字格式需要编辑模式和文字选区，撤销需要已有操作，演示需要满足标题规则。
2. 完成输入法选字；若正在输入属性或局部原文，先提交或取消该处草稿，再执行文档操作。
3. 检查浏览器、系统和键盘布局是否占用了按键。使用上面的按钮或菜单路径，避免假定浏览器原生“另存网页”已经保存了 Yeli。
4. 仍不可用时，查[完整命令的生效条件](commands.html)及[兼容性排错](compatibility.html)。
