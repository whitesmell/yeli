# 第一次编辑与保存

## 准备一份可信文件

从你信任的来源取得 `.yeli.html`，下载到电脑后用浏览器打开。无需注册或启动服务器。网页里的附件预览可能会禁用交互；此时先下载文件，而不是在附件缩略图里编辑。

也可以从网站的“在线编辑器”入口开始：Markdown 只在本机浏览器中处理，不上传文件，网页保存会下载 `.md`。若之后需要一份可离线继续编辑的完整文件，在该网页导出可编辑 `.yeli.html`，再按下文步骤重新打开。

## 用一分钟完成第一轮

1. 在预览页面选择“编辑”。单击正文段落，写下“我的第一份 Yeli 文档”。
2. 修改顶部文档标题。需要章节时，在空白区块输入 `/`，选择二级标题。
3. 按 `⌘/Ctrl + S`，或打开“更多”，直接选择“保存”或“下载更新副本”。文件是菜单分区，不是子菜单。留意结果：可能写回原文件，也可能下载新副本。
4. 如果提示写回，找到原文件；如果提示下载，在下载目录找到最新的 `.yeli.html`。重新打开实际保存的文件，确认标题与正文仍在。

成功标准是**新文件重新打开后有你的修改**。浏览器恢复记录和页面上的内容不能代替磁盘上的文件。

## 开始另一份文档

保留一份未修改的可信起始文件，每次复制后开始新文档。也可以从现有 Yeli 中选择“更多 → 打开文件”，导入新的 `.md`，再保存为 `.yeli.html`。当前没有必须使用的账号或云端“新建”流程。

## 分享前检查

希望接收方继续编辑，就分享可信的可编辑副本；只需阅读则使用只读导出。邮件和聊天工具可能拦截 HTML 附件，先确认传输渠道。参见[保存与冲突](save.html)及[导入导出](export.html)。
