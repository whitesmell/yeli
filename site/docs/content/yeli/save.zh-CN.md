# 保存、副本与冲突

## 选择保存方式

使用 `⌘/Ctrl + S`，或打开“更多”直接选择保存项：按环境显示“保存”或“下载更新副本”。支持直接写入且已授权的浏览器可以保存原文件；其他环境下载包含修改的新副本。“保存副本”保留独立版本。核对写回或下载结果，在文件管理器找到最新文件。

文件选择与写入权限由你授予。通过下载获得副本不会自动建立长期写回权限；浏览器原生“保存网页”也不是 Yeli 的文档保存操作。

## 原文件被外部修改

Agent 或其他工具改过磁盘文件后，旧页面再写回可能出现冲突。先保留当前编辑副本，再查看磁盘上的新文件；不要直接覆盖不认识的变化。文件指纹检查是尽力检测，不是多编辑器的事务锁。

重开、授权丢失或文件句柄不可用时，按重新关联提示选择目标文件并核对。无法关联就保存新副本；不要为了继续操作去删除别人的修改。

## 保存状态在哪里

“关于 Yeli”展示当前完整文件大小及保存/恢复状态。恢复仅在浏览器中存在，不能代替文件。保存失败时可先导出 Markdown 保住正文，再处理权限或空间问题。

文档连同运行时和内嵌图片一起计入文件大小。KB / MB 采用十进制，精确字节可核对；资源限制和传输限制各自存在。分享前阅读[兼容性](compatibility.html)。
