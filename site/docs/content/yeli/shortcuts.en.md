# Keyboard shortcuts

This page lists shortcuts and local interaction keys. For menu locations use the [feature overview](overview.html); for actions without shortcuts use the [complete command reference](commands.html).

## Start with a few keys

Remember Save `⌘/Ctrl + S`, Find `⌘/Ctrl + F`, Undo `⌘/Ctrl + Z` and Bold `⌘/Ctrl + B`. When unsure, open the in-app Shortcuts & Markdown guide with `⌘/Ctrl + /`; press it again to close.

`⌘` is Command on Mac, `Shift` is the shift key and `Ctrl` is Control. Hold the keys of a combination together. “—” means no binding is registered in that column. Platform columns are separate: do not press both Command and Control. Tables come from the current application catalog. On narrow screens, swipe tables sideways to see the other platform and conditions.

## Button and menu alternatives

- Save: open More and choose the current save action. Capable environments can write back; others download an updated copy. Check the actual file to confirm success.
- Search: use the top Search button. Full-text search finds body text; the outline filter only searches headings.
- Outline: click the entire Yeli logo at the top left.
- Font size, Page width and Present: choose the matching action in More. Font/width shortcuts cycle settings; the presentation shortcut opens or closes presentation.
- Selection formatting: enter Edit, select text and use the floating tools. Repeating a shortcut cannot replace a missing selection.

## Local interaction keys

These work in the relevant control or view, rather than as global commands.

| Current context         | Keys                            | Result                                               |
| ----------------------- | ------------------------------- | ---------------------------------------------------- |
| Empty block             | `/`                             | Open the slash menu; type keywords to filter         |
| Slash menu              | `↑` / `↓`, `Home` / `End`       | Previous/next item, or first/last item               |
| Slash menu              | `Enter` / `Escape`              | Run the selected item / close the menu               |
| Search input            | `Enter` / `Shift + Enter`       | Next / previous match                                |
| Search panel            | `Escape`                        | Close search and return to the previous location     |
| Table size picker       | Arrow keys, `Enter` / `Space`   | Move the dimension selection and activate its button |
| Single-line property    | `Enter` or blur; `Escape`       | Commit; cancel the current draft                     |
| Multiline/list property | `⌘/Ctrl + Enter`; `Escape`      | Commit; cancel the current draft                     |
| Presentation            | `←` / `→`; `Escape`             | Previous/next section; exit fullscreen or close      |
| Dismissible dialog      | `Tab` / `Shift + Tab`; `Escape` | Move focus; close                                    |

## If nothing happens

1. Check mode and target: formatting needs Edit and selected text, Undo needs a previous operation, and Present needs eligible headings.
2. Finish IME composition. If editing a property or local source, commit or cancel that draft before a document action.
3. Check whether the browser, operating system or keyboard layout intercepts the key. Use buttons or menus instead; browser Save page is not proof that Yeli saved.
4. Consult [command conditions](commands.html) and [compatibility troubleshooting](compatibility.html) if it remains unavailable.
