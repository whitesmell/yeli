# 强调、删除线与嵌套

## 基础强调

```markdown
_需要关注_
**必须完成**
_**同时粗体与斜体**_
~~已被替代的结论~~
```

单星号表示斜体，双星号表示粗体，三个星号可组合。删除线使用两个波浪号，是扩展语法，Yeli 当前支持。下划线也可表示强调，但词中下划线和嵌套的规则更容易产生误会；日常统一用星号。

## 嵌套与空格

标记应贴近要强调的文字：`**重要**` 比 `** 重要 **` 可靠。嵌套可写 `**预算中 *待确认* 的部分**`，但混合层级太多会降低源文本可读性。中文标点与复杂边界处可能受到分隔符规则影响，检查实际渲染。

不想加粗时写 `\*\*字面符号\*\*`，或把语法放进行内代码。代码里的 `**` 不会变成粗体。

## 在 Yeli 中练习

输入一段正文，选中一个词使用浮动工具加粗，再对另一个词添加删除线。导出 Markdown，检查只在对应范围添加标记。撤销后其他文字应保持原样。快捷操作见[正文编辑](../yeli/writing.html)。
