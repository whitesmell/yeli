# 扩展语法与 Yeli 支持表

## 按实现判断，不按文件名猜测

Markdown 方言和插件各不相同。下表依据当前默认 Yeli 渲染器：支持表格、删除线与自定义任务渲染；未启用脚注等插件，`html`、裸文本 `linkify` 关闭。官方高级源码构建也不自动开启这些扩展。

| 语法           | 常见写法                 | 当前 Yeli                       |
| -------------- | ------------------------ | ------------------------------- |
| 表格与对齐     | 管道、短横线与冒号       | 支持                            |
| 围栏代码/语言  | 三反引号后写 `js`        | 显示代码，不保证高亮            |
| 删除线         | `~~text~~`               | 支持                            |
| 任务           | `- [ ] task`             | 支持，编辑模式可切换            |
| 尖括号自动链接 | `<https://example.com>`  | 支持安全地址                    |
| 裸网址自动链接 | `https://example.com`    | 不自动链接                      |
| 脚注           | `text[^1]`、`[^1]: note` | 未启用脚注渲染                  |
| 指定标题 ID    | `## Title {#id}`         | 未启用属性语法                  |
| 定义列表       | 词后下一行 `: 解释`      | 未启用                          |
| emoji 简码     | `:smile:`                | 不转换；直接 Unicode 表情可显示 |
| 高亮           | `==text==`               | 未启用                          |
| 下标/上标      | `H~2~O` / `x^2^`         | 未启用                          |
| 数学           | `$x^2$` / `$$...$$`      | 未启用 KaTeX 等引擎             |
| 图表           | `mermaid` 围栏           | 作为代码，不生成图表            |
| 原始 HTML      | `<div>...</div>`         | 不执行，不作为作者 HTML 渲染    |

## 看懂未启用语法

```markdown
结论来自证据[^evidence]。

[^evidence]: 原始记录。

术语
: 简短解释

## 结果 {#result}
```

在支持相应插件的工具里，上述内容可能生成脚注、定义列表和自定义锚点。在当前 Yeli 中它可能按普通文本或原文区块保留；“原文没丢”不代表目标语义已渲染。

## 跨工具交付策略

优先使用标准链接代替脚注跳转、普通列表代替定义列表、文字说明代替数学与图表。必要图表可用外部工具生成 PNG/WebP 后嵌入，并保留原始图表源码。文字中的 Unicode 表情可能因字体不同而外观变化。

遇到扩展显示差异，先识别方言和引擎，不要反复保存试图“修复”语法，也不要承诺无损转换所有渲染效果。
