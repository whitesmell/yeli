# 表格、任务与 GFM 常用扩展

## 表格

```markdown
| 任务 | 负责人 | 工时 |
| :--- | :----: | ---: |
| 规划 |  Lin   |    2 |
| 制作 |  Sam   |    4 |
```

表头和分隔行的列数应相同，分隔行用短横线，可用冒号控制左、中、右对齐。单元格内部可写粗体、行内代码和链接；换行、嵌套列表和合并单元格不是可靠的管道表格能力。单元格中显示管道字符请转义为 `\|`。

Yeli 支持表格渲染与行列编辑。它不计算工时总和；需要数据计算时先用表格工具算好再写入。宽表在自己的滚动区域阅读。

## 任务列表

```markdown
- [ ] 检查来源
- [x] 完成初稿
- [ ] 保存并重新打开
```

方括号中空格表示未完成，`x` 表示已完成，后面要有空格再写文字。Yeli 编辑模式可以切换任务状态；预览中的任务不用于直接写入。复选框只是文档内容，不提供人员指派、提醒或后台工作流。

## 删除线与兼容

`~~旧结论~~` 可标记废弃内容。表格、任务与删除线不是 2004 年原始 Markdown 的全部通用基础；发到另一个工具前，检查它是否支持这些扩展。GFM 还定义其他规则，当前 Yeli 并非完整 GitHub 网站模拟器。
