# 标题、段落、换行与分隔线

## 标题表达层级

在行首写一至六个 `#`，后跟空格与标题。一般用一个一级标题表达文章主题，二级标题组织章节，三级标题组织小节。不要因为想缩小字号而跳过逻辑层级。

```markdown
# 项目手册

## 安装

### 前提条件
```

Setext 也可用下一行的 `===` 表示一级标题、`---` 表示二级标题。它容易与分隔线混淆；教程和跨工具文档优先用井号写法。Yeli 目录从标题派生，不要手工维护另一份标题清单。

## 段落与换行

空一行开始新段落。同一段中的单次回车是软换行，通常显示为空格，不能依赖它强制换行。需要诗句或地址分行时，可在行尾加两个空格或 `\` 再换行；尾随空格不易察觉，检查渲染结果。

```markdown
这是第一段。
继续写仍属于第一段。

这是第二段。

地址第一行\
地址第二行
```

普通正文不要在行首随意加四个空格，否则可能变成代码块。全角井号和没有空格的 `#标题` 不应当作可靠标题写法。

## 分隔线

独立一行使用至少三个 `*`、`-` 或 `_`，前后空行降低歧义。例如 `***`。在紧接正文下一行写 `---` 可能得到二级标题；在文件开头的成对 `---` 还可能是 [frontmatter](frontmatter.html)。

练习：写两个段落和两个二级标题，查看 Yeli 目录并点击跳转。
