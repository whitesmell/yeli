# 链接、图片与引用链接

## 普通与引用链接

```markdown
[示例网站](https://example.com "访问说明")
[规范][spec]

[spec]: https://spec.commonmark.org/0.31.2/ "CommonMark"
```

方括号是可见名称，圆括号是目的地址，可选引号内容是标题。引用链接把地址集中放到定义处；完整、折叠和简写引用都依赖匹配的定义。地址含空格时优先使用编码或尖括号包围合法目标，避免未配对括号。

链接文字应说明目的，如“安装步骤”，避免只有“点击这里”。标题锚点生成规则由渲染器决定，跨工具发布要点击验证；`{#id}` 不是当前 Yeli 标题属性语法。

## 自动链接

`<https://example.com>` 与 `<writer@example.com>` 是标准尖括号自动链接写法。GFM 还描述裸网址扩展。Yeli 当前关闭裸文本 linkify，写明确的 `[名称](地址)` 最稳妥；不要假定 `www.example.com` 会自动可点击。

## 图片

```markdown
![流程图：输入、校验、输出](diagram.png "文档流程")
[![预览图](thumb.png)](https://example.com)
```

感叹号让链接结构变成图片。替代文字说明图片信息；相对路径依赖所在目录，移动 `.md` 时要同时搬迁资源。Yeli 不自动加载这些外部图片，要离线携带请[嵌入本地图片](../yeli/media.html)。

只使用你愿意打开的协议与来源；渲染器可能禁用不安全协议。练习：写一条有意义名称的链接，并用引用定义复用同一个地址。
