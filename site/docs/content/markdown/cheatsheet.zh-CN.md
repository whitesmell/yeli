# Markdown 语法速查

## 常用写法

| 目标          | 源码示例                      | 说明                   |
| ------------- | ----------------------------- | ---------------------- |
| 一级/二级标题 | `# 标题` / `## 小节`          | 井号后加空格           |
| 段落          | 两段之间空一行                | 单个换行通常还是同一段 |
| 硬换行        | 行尾两个空格或反斜线          | 优先分段，必要时才用   |
| 粗体/斜体     | `**重点**` / `*强调*`         | 符号成对               |
| 删除线        | `~~旧内容~~`                  | 扩展；Yeli 支持        |
| 引用          | `> 引用内容`                  | 可嵌套                 |
| 无序/有序列表 | `- 项目` / `1. 步骤`          | 子项按层级缩进         |
| 任务          | `- [ ] 检查` / `- [x] 完成`   | 扩展；编辑模式可切换   |
| 行内代码      | `` `value` ``                 | 保护其中的符号         |
| 分隔线        | `***`                         | 独立成段               |
| 链接          | `[名称](https://example.com)` | 地址与名称分开         |
| 脚注          | `正文[^1]`、`[^1]: 注释`      | 支持编辑、阅读与导出   |
| 图片          | `![说明](image.png)`          | Yeli 离线使用需嵌入    |
| 转义          | `\*字面星号\*`                | 显示标记字符           |

## 多行结构

````markdown
```js
const ready = true;
```

| 方案 | 状态 |
| :--- | :--: |
| A    | 就绪 |
````

代码围栏后的语言名是标识，不保证有语法高亮。表头后必须有分隔行。

## 不应直接套用的写法

标题 ID `{#id}`、定义列表、高亮 `==text==`、上下标、数学与 Mermaid 依赖具体实现。当前 Yeli 不把它们当作已启用扩展渲染。裸网址也不会自动变成链接；使用明确的链接语法。脚注的续行与引用规则见[扩展表](extensions.html)。

需要按步骤学习时，从[标题与段落](headings-paragraphs.html)开始；工作时可收藏本页。
