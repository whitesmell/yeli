# 行内代码与代码块

## 行内代码

用一对反引号保护命令、文件名或语法：`` `npm run build` ``。内部若包含反引号，可用更长的反引号包围，例如用两个包围一个。代码中的星号与下划线保持字面含义。

## 围栏代码

围栏至少三个反引号或波浪号，结束围栏使用相同字符且长度不少于开头。语言名帮助读者识别，不会让代码执行，也不保证高亮。

````markdown
```python
print("hello")
```
````

要在教程中展示三反引号，可以用四反引号作为外层围栏；结束后留空行继续正文。没有正确关闭的围栏会把后续内容都包含进代码区。

## 缩进代码与当前支持

四空格缩进也能形成代码块；列表中的缩进另有层级要求。复制命令时留意智能引号、前导提示符和占位参数，理解后再运行。

Yeli 显示围栏代码及语言信息，但当前没有承诺所有语言的语法高亮。`mermaid` 和 `math` 语言标签不会自动启用图表或数学引擎，见[扩展语法](extensions.html)。

练习：在一个代码块里写 `# 这不是标题`，检查它不进入目录；用区块原文只修改代码内容，保存后重开。
